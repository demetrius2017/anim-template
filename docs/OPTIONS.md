# Дополнительные возможности движка

## Горизонтальный кадр 16:9

В `story.py` ролика: `E.write(..., frame=[640, 360])`. Сцена рисуется в координатах 640×360 и рендерится в 1920×1080
(субтитры уходят вниз кадра, класс `#root.land`). По умолчанию `[360, 640]` — вертикальный 1080×1920, как раньше.
Сцены под горизонтальный кадр пишутся отдельно: старые сцены рассчитаны на 360×640.

Ширина строки субтитров: `E.cap_chars = 40` (по умолчанию 14 знаков), `E.cap_lines = 2`.

## Данные и картинки ролика

`E.write(..., scripts=["eps/<имя>/assets/data.js"])` — js-файлы ролика (ряды для графиков, логотипы в data URI),
пути от корня репозитория; `render.py` подключает их после сцен. Картинки из `window.PRELOAD = [url, ...]`
декодируются до первого кадра — логотипы не «мигают» на первых кадрах.

## Разрешение и качество

```bash
RENDER_SCALE=4 python build.py <имя> --skip-tts                 # 4× от кадра: 640×360 -> 2560×1440 (2K)
RENDER_SCALE=4 ENCODE_CRF=12 python build.py <имя> --skip-tts   # мастер для публикации (меньше CRF — выше качество)
```

`RENDER_SCALE` по умолчанию 3 (1920×1080 / 1080×1920), `ENCODE_CRF` — 17.

## Голос OpenAI вместо edge-tts

Файл `eps/<имя>/tts.json`:

```json
{
  "provider": "openai",
  "model": "gpt-4o-mini-tts",
  "voices": {
    "narr": {"voice": "cedar", "speed": 1.3, "language": "ru",
             "instructions": "Ты диктор динамичного делового ролика. Говори чисто, энергично, в бодром темпе."}
  }
}
```

Нужен `OPENAI_API_KEY` в окружении и `pip install openai`. Синтез — `gpt-4o-mini-tts` (голоса: alloy, ash, ballad, cedar,
coral, echo, fable, marin, nova, onyx, sage, shimmer, verse), границы слов — распознавание `whisper-1`, сшитое со словами
сценария (`tts_openai.py`): числа, которые распознавание пишет цифрами, получают время своего участка.
`speed` реально меняет темп (1.2–1.3 — бодро для русского, около 1.1 — для английского).
Настройки голоса попадают в `build/tts_manifest.json`: после их смены `--skip-tts` потребует новую озвучку.
Знак ударения U+0301 в OpenAI не передаётся (модель ставит ударения сама); для edge-tts он по-прежнему работает.
Стоимость — около $0.02 за минуту речи (синтез + распознавание).
