# R5. Генеративные модели видео, голоса и музыки через API

Срез: **18 октября 2026 года**. Задача: выбрать инструменты для вертикальных научно-популярных роликов и микродрам `anim-template`. Все суммы — USD, без налогов. Проверены открытые официальные страницы и репозитории; платные генерации, доступ конкретного аккаунта и качество русского на слух **не тестировались**. «Подтверждено» ниже означает подтверждение документацией, а не успешный production-вызов. Число дублей, художественный выбор и бюджеты производства — наши плановые оценки, не статистика провайдеров.

## Главное (10 пунктов)

1. **Модель должна снимать конкретный план, а не придумывать смысл ролика.** Для `spy_flow` сначала нужен один вопрос и причинный ответ; дорогие кадры не исправят скачки между бэктестом, кредитом, устройством индекса и издержками. Это редакционная оценка по [текущему сценарию](../eps/spy_flow/build/script.json). Планировать историю до генерации рекомендует и [Runway](https://help.runwayml.com/hc/en-us/articles/26871350018835-How-to-create-longer-videos-and-films).
2. **Рекомендуемый старт — гибрид:** 40–45 секунд наших схем и типографики, 15–20 секунд модельных персонажей/B-roll. Движок отвечает за проверяемую информацию; модель — за выражение лица, среду, свет и физическое действие. Это предложение для проекта, не обязательная пропорция для всех жанров.
3. **Сравнивать нужно endpoint и настройки, а не бренд.** Пять секунд, десять секунд, reference-video, звук и upscale могут иметь разные формулы. Например, у [Luma Ray3.2](https://docs.agents.lumalabs.ai/guides/pricing/) 720p/5 с стоит $0.30, а 10 с — $0.90.
4. **Sora API исключить из нового конвейера.** OpenAI указала отключение на 24.09.2026; карточка WaveSpeed предупреждает о временной недоступности и возможности замены модели без уведомления. [OpenAI](https://developers.openai.com/api/docs/deprecations), [WaveSpeed](https://wavespeed.ai/models/openai/sora-2/text-to-video).
5. **Для русского рассказчика — отдельный TTS и утверждённая звуковая дорожка.** Русский в списке языков не доказывает правильность ударений и актёрскую убедительность. Нативная речь видеомодели усложняет исправления; у [Kling v3 на fal](https://fal.ai/models/fal-ai/kling-video/v3/pro/text-to-video/api) документировано преобразование языков вне китайского/английского в английский.
6. **Голос закупать с учётом жизненного цикла.** OpenAI объявила отключение `tts-1`, `tts-1-hd` и snapshots `gpt-4o-mini-tts` на 06.01.2027; новое долгоживущее решение на них не фиксировать. [Официальное уведомление](https://developers.openai.com/api/docs/deprecations).
7. **Консистентность — отдельная работа:** утверждённые изображения героя с разных сторон, одежда, реквизит, положение в сцене, единый голос. References уменьшают вариации, но не заменяют приёмку. [Runway: character plates](https://help.runwayml.com/hc/en-us/articles/26871350018835-How-to-create-longer-videos-and-films).
8. **Музыка должна иметь подтверждённый путь API → файл → коммерческое использование.** Наличие красивого веб-сервиса или стороннего «Suno API» этого не доказывает. Suno/Udio и действующие музыкальные API разобраны отдельно ниже.
9. **MCP полезен для выбора и проб, API/CLI — для повторяемой сборки.** У fal, WaveSpeed и Replicate есть официальные интеграции; старый ElevenLabs MCP архивирован. Наличие MCP не означает наличие бесплатных генераций, SLA или автоматического монтажа.
10. **Покупать пригодные секунды, считать все оплаченные.** Предлагаемые лимиты на 60 секунд: экономный гибрид $10–15, основной $25–40, постановочная микродрама $130–160 переменных расходов. Подписки, пополнение баланса, труд и первоначальные тесты считаются отдельно; формулы приведены ниже.

## Основная часть

### 1. Где нужна генеративная модель

| Задача кадра | Исполнитель | Почему |
|---|---|---|
| График, размер портфеля, доли, даты, причинная схема, формула | SVG/JS | Точные числа, повторяемость, исправление без перегенерации сцены |
| Жест, взгляд, бытовое действие, фактура города/комнаты, атмосферная перебивка | Видеомодель | Такие планы трудно и дорого убедительно анимировать простыми SVG |
| Научный процесс, которого никто не снимал | Проверенная схема; модель — только явно обозначенная реконструкция | Фотореализм сам по себе не является доказательством корректности |
| Говорящий герой крупным планом | Утверждённый голос + avatar/lipsync | Слова и характер можно принять до дорогой обработки лица |
| Типографика и субтитры поверх живого кадра | Наш движок | Контроль русского текста, безопасных зон и времени каждого слова |
| Короткий щелчок, удар, сигнал в точный момент | `mixlib.py` или проверенный SFX | Не нужно генерировать весь аудиомир ради одного точного события |

Это наша схема распределения работы. Она расширяет исходное правило [CLAUDE.md](../CLAUDE.md) о рисованных сценах; исследование не меняет художественный стандарт проекта автоматически. Для перехода к реалистичным людям сначала нужен выбранный владельцем стиль.

### 2. Как читать цены

**Секунда генерации ≠ секунда монтажа ≠ секунда GPU.** Если из пятисекундного дубля в ролик вошло две секунды, оплачены пять. Если потребовалось три дубля, оплачены пятнадцать. У Replicate часть моделей тарифицируется вычислительным временем, часть — выходом; сравнивать GPU-second с video-second нельзя. [Replicate pricing](https://replicate.com/pricing).

В таблицах «$/с» — цена выходной секунды, если не указано иное; пересчёт из цены клипа применим только к указанной длине. «720p/1080p» — название режима провайдера: для портрета нужно проверить реальные размеры через `ffprobe`. Выход 1080×1920 после масштабирования из 720p не становится нативным 1080p.

### 9. Практический конвейер шортса и микродрамы

**Что подтверждено практическими руководствами:** Runway описывает цепочку история → раскадровка → изображения персонажей → планы → монтаж; отдельно рекомендует нейтральные изображения героя с разных углов. Руководство по диалогам начинает с записи реплик, затем создаёт базовое видео, исполнение каждого персонажа и собирает результат в редакторе. Это пример реального инструментария производителя, не доказательство, что так работают все успешные студии. [Длинные фильмы из клипов](https://help.runwayml.com/hc/en-us/articles/26871350018835-How-to-create-longer-videos-and-films), [диалоги Act-Two](https://help.runwayml.com/hc/en-us/articles/41748090660499-Creating-Multi-Character-Dialogues-with-Act-Two).

**Предлагаемый процесс для нас:**

1. **Смысл:** одним предложением — что зритель должен понять или почувствовать. Для научпопа: вопрос → механизм → проверка → ответ. Для драмы: желание героя → препятствие → действие → цена выбора. Не генерировать дорогие планы до принятия этой цепочки.
2. **Сценарий и звуковой черновик:** согласовать текст, произношение, паузы и поворот. Записать rough voice; после принятия — финальный голос. Диалоги делать до lip sync. Не подгонять смысл под случайно красивый дубль.
3. **Таблица планов:** для каждого кадра записать его смысловую функцию, действие, начало/конец, источник — SVG или модель, референсы, звук, критерий брака. На экране 2–3 с могут происходить внутри оплаченного клипа 5–8 с; это учитывать в расходах.
4. **Паспорт персонажа:** лицо анфас/профиль/три четверти, полный рост, силуэт, одежда, предмет в руках, voice ID. Отдельно — декорация и карта расположения людей. Использовать утверждённые исходники, не цепочку из случайных предыдущих дублей.
5. **Ключевые изображения:** сначала проверить композицию всех планов на одном листе. Для 9:16 заложить место субтитрам: в нашем формате важные объекты выше `GROUND=372` из 640. Не пытаться спасти горизонтальный общий план сильным обрезанием.
6. **Движение:** image-to-video для утверждённого кадра; в запросе одно главное действие, направление взгляда/движения и одна камера. Text-to-video оставить для безличного атмосферного B-roll. У references принять лицо, возраст, одежду и реквизит отдельно; качество одного не гарантирует другое.
7. **Речь в кадре:** выбрать avatar или lipsync только для планов с видимым ртом. Реакции, руки, общий план и слушающий герой позволяют сохранить драму без непрерывного крупного плана говорящего. Диалог двух людей сначала проверить на двух коротких одиночных планах.
8. **Черновой монтаж:** отобрать пригодные куски, построить переходы по действию и звуку. Проверить, что следующая сцена отвечает на предыдущую. Проверить направления взглядов и движения, предметы и причинность.
9. **Финальный звук:** отдельные дорожки voice, ambience, музыка, события. Нативный звук видео либо осознанно использовать, либо удалить; не накладывать второй голос и случайную модельную музыку под диктора. Для проекта — ducking и около −15 LUFS согласно [CLAUDE.md](../CLAUDE.md).
10. **Приёмка:** просмотр без звука, прослушивание без картинки, затем полный просмотр на телефоне. Проверить смысл, русский, лица/руки, safe area, мерцание, точность данных, права и фактическую стоимость. Для науки — отдельно сверить каждое утверждение с источником; B-roll не засчитывать как источник.

**Консистентность:** фиксированные reference assets и версия модели важнее надежды на один `seed`. Для сложного изменения сначала получить новый утверждённый кадр, потом анимировать. Runway рекомендует нейтральное освещение и пошаговые изменения; Veo прямо предупреждает, что seed не гарантирует детерминизм. [Image references](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References), [Veo](https://ai.google.dev/gemini-api/docs/veo). Долгие extensions удобны технически, но в нашем монтаже не заменяют смену планов и контроль накопленных изменений.

### 10. Смета на 60-секундный ролик

Русскую речь генерируем отдельно; оплата нативного звука Veo в C не отменяет TTS, если его диалог заменяется.

**Почему именно столько:** A покупает немые атмосферные вставки; B — несколько более сложных действий и один короткий говорящий план; C — постановочные сцены и больше дублей. Доли брака не измерялись. После первых трёх планов заменить эти допущения реальными показателями: `стоимость принятых секунд = все списания за видео / секунды, вошедшие в монтаж`.

**Чувствительность:** один дополнительный дубль всех планов добавит A $0.76, B $3.36, C $25.60 только за видео. Если в C потребуется восемь попыток вместо четырёх, только видео будет стоить $204.80, лимита $160 уже недостаточно. После двух безрезультатных изменений запроса пересматривать план/референс/модель, а не бесконечно оплачивать тот же замысел. Это предлагаемое правило контроля бюджета.

**Что не включено:** сценарист/режиссёр/монтажёр, настройка интеграции, комиссия/налоги, локальный рендер, хранение, платный upscale, подписка инструмента для lip sync, минимум пополнения кошелька, оригинальная запись актёра. Веб-подписка поставщика обычно не заменяет API-биллинг — конкретный путь указан выше.

**Как считать подписку без двойного счёта:** таблица показывает стоимость потреблённых единиц. Для N роликов в месяц общая денежная затрата на подписной сервис — `месячный план + overage`, а не `месячный план + повторная стоимость уже включённых единиц`. Разделить её на N. Например, Starter ElevenLabs $6 — минимум $6 на один ролик, если больше ничего в месяце не произведено; на десять роликов — $0.60/ролик до превышения лимитов. Creator $22 нужен при выбранных функциях вроде PVC, а не потому, что любая озвучка его требует. [ElevenAPI pricing](https://elevenlabs.io/pricing/api).

**Практический выбор:** начать с B, но провести пилот на 15–20 секундах с лимитом $30–50. Его результат — выбранный голос, проверенная вертикаль/персонаж, фактическая цена принятого плана и рабочий импорт, а не просто папка красивых генераций. На длинную серию закладывать стоимость переиспользуемого паспорта персонажа отдельно от каждого эпизода.

## Что взять в наш движок/процесс (конкретно)

**Что уже обнаружено в рабочем дереве:** [storylib.py](../storylib.py) имеет `E.video(path, t_start, in_=..., out=..., speed=..., fit=...)`; [media_assets.py](../media_assets.py) декодирует локальный MP4 в кэш кадров CFR 30 fps с хешами; [runtime.js](../engine/runtime.js) кладёт кадр под общие overlays/captions. Звук MP4 явно исключён из этого пути. [tts.py](../tts.py) пока напрямую использует `edge_tts`. Это чтение текущих, в том числе незакоммиченных файлов; запуск и приёмка этих изменений в задачу исследования не входили.

| Приоритет | Конкретное изменение процесса/контракта | Признак готовности |
|---|---|---|
| P0 | Один вопрос/конфликт и причинная цепочка до закупки кадров | Человек пересказывает смысл после одного прослушивания черновика |
| P0 | Контрольный набор из 3 планов: герой, действие, переход к схеме | Лист кадров и короткий монтаж выдерживают стиль и смысл; известна цена пригодного плана |
| P1 | Адаптеры генерации вне JS-рендера: `quote → submit → status → download` | Возобновление по job ID без повторной оплаты; сборка работает с локальными файлами |
| P1 | Манифест ассета: provider, endpoint/version, prompt, refs/hash, seed, job ID, цена quote/actual, дата, условия, output hash | Для каждого используемого файла понятны происхождение, расходы и права |

| P1 | Явный импорт аудио из клипа с теми же in/out/speed и размещением на общей шкале | Хлопок/закрытие двери совпадают с кадром; голос не дублируется |
| P1 | Предпроверка MP4: размеры, fps, длительность, цвет, аудиодорожки, safe crop | Ни один клип не обрезает рот/предмет или не кончается раньше монтажного окна |
| P2 | Утверждённые персонажи и style bible на серию | Один герой узнаваем в 3 разных планах; смена модели требует повторной проверки |
| P2 | Отчёт по расходам и браку | Видны оплаченные секунды, принятые секунды, причина отказа и стоимость исправления |

**Гибридный стартовый набор:** один агрегатор — WaveSpeed или fal после одинакового пилота; Veo Fast через Gemini как отдельный проверяемый вариант; ElevenLabs для финального русского после прослушивания; `edge-tts` для черновиков; музыка Stable Audio/ElevenLabs при подтверждённых правах; короткие точные эффекты оставить `mixlib.py`. Не закупать одновременно все подписки. Lip sync добавлять только при принятом решении показывать говорящего героя.

**Как применить к `spy_flow`:** наша редакционная гипотеза — сфокусировать новый ролик на одной проверяемой ошибке: «почему эффектный тест ещё не доказывает преимущество». Модельные планы: человек замечает красивую кривую; реакция на исчезнувшее преимущество; возвращение к спокойному решению. Состав выборки, сравнение, просадку и издержки показывать точными SVG. Объяснение денежного потока вынести в другой сюжет, если оно не нужно выбранной причинной цепочке. Это предложение сценарного направления, не подтверждение финансовых тезисов исходного ролика.

### Что нужно от владельца

1. **Стиль и задача:** реалистичные люди, стилизованные персонажи или только B-roll; научпоп либо микродрама; один критерий успеха пилота.
2. **Учётные записи:** один из WaveSpeed/fal; ElevenLabs с подходящими коммерческими правами; Gemini API с биллингом — если проверяем Veo; Stable Audio — если выбран для музыки. Replicate/Runway/Luma/Kling direct подключать по результату, а не заранее.
3. **Ключи и лимиты:** отдельные project API keys вне Git и промптов, ограничение месячного расхода, сумма на один ролик и число дублей. Для Kling direct — реквизиты API-авторизации из кабинета; не пользовательский пароль.
4. **Права:** согласие на использование лица/голоса, исходные референсы с понятной лицензией, назначение музыки — органическая публикация, реклама, клиентский заказ. Публичная фотография не заменяет согласие на синтетического персонажа.
5. **Бюджет пилота:** предлагаем $30–50 переменных расходов на одинаковый тест двух видеомаршрутов, русского голоса и 15–20-секундной сборки; обязательные минимальные платежи — отдельно. После пилота выбрать лимит одного из вариантов сметы.
6. **Приёмка:** прослушивание голоса, выбор персонажа и один просмотр чернового монтажа до массовых генераций. Это необходимые творческие решения; в рамках этого исследования оплаченные действия не запускались.
