# Как в этом репозитории делается ролик (инструкция для ИИ-агента)

Это движок вертикальных анимационных роликов 9:16 (TikTok, Shorts, Reels): рисованные сцены на SVG, живая камера, озвучка нейроголосом, субтитры по словам, звук. Картинку не генерирует нейросеть и это не слайд-шоу: каждую сцену ты пишешь кодом (JS-функция возвращает SVG на момент времени t), движок рендерит 30 кадров в секунду.

Отвечай пользователю по-русски, простыми словами: он не программист.

## Как устроено

```
engine/index.html   холст 360×640 (рендер ×3 = 1080×1920), субтитры, плашки
engine/lib.js       примитивы и готовые рисунки: R L Ci P T G, person, door, windowW, phone, peephole, palette C, GROUND=372
engine/runtime.js   камера, плашки (stk/chip/track/vf/peek), субтитры, цветовые фильтры look
engine/scenes.js    маленькие демо-сцены
engine/scenes/*.js  сцены: «Многоэтажка» (квартира ночью) и «Школа ночью» — каталог в docs/SCENES.md
tts.py              озвучка: script.json -> audio/voice_<голос>.wav + build/words.json (время каждого слова)
stress_check.py     проверка ударений диктора (рискованные слова + файл на прослушивание)
storylib.py         раскадровка: E.shot(...) кадры, E.add(...) плашки, субтитры страницами
mixlib.py           звук: голоса, подложки, синтез простых эффектов, громкость -15 LUFS
render.py           кадры через Chrome/Chromium (Playwright); --at ... --sheet — лист кадров
scene_test.py       одна сцена без озвучки -> лист кадров
build.py            всё вместе: python build.py <имя>
eps/<имя>/          ролик: build/script.json (текст), story.py (раскадровка), mix.py (звук)
```

Пример — `eps/example` (20 с). Новый ролик начинай с копии этой папки.

## Порядок работы над роликом

1. **Сценарий** — `eps/<имя>/build/script.json`. Правила формата — `docs/FORMAT.md` (хук, правила с причинами, зло действует, финал). Фразы короткие, разговорные. Разметка: `*слово*` — выделенное, `~слово~` — красное (опасность). Поле `voice` — голос из `tts.py` (`narr` по умолчанию; `kol` — «устройство», `rec` — шёпот/запись, `pa` — громкая связь, `tema` — парень из телефона, `boy` — мальчик издалека). Покажи текст пользователю до озвучки.
2. **Сцены.** Сначала подбери готовые из `docs/SCENES.md`. Не хватает — напиши новую в `engine/scenes/<префикс>_<имя>.js` (правила ниже) и проверь: `python scene_test.py <сцена> '<json p>' --dur 6 --at 0,1,2,3,4,5 --look night --out qa/scene_<сцена>.jpg`. **Открой картинку и посмотри сам** — исправляй, пока не будет хорошо.
3. **Озвучка, раскадровка, звук:** `python build.py <имя> --no-render`. Времена в `story.py` бери из озвучки: `t("id")`, `te("id")`, `wf("id", "начало_слова")` — никогда не пиши секунды руками.
4. **Лист кадров:** `python build.py <имя> --skip-tts --sheet` → открой `eps/<имя>/qa/sheet.jpg`, проверь каждый кадр (чек-лист ниже). Нужен лист в конкретные моменты — `python render.py --story eps/<имя>/build/story.json --at 1,2.5,4 --sheet eps/<имя>/qa/at.jpg`.
5. **Полный рендер:** `python build.py <имя> --skip-tts` → `eps/<имя>/out/<имя>.mp4` и лёгкая копия `<имя>_small.mp4`.

В форке Дмитрия шаги 2–5 (проверка сцен, раскадровка, звук, листы, рендер) идут на GPU-станции — следующий раздел.

## Рендер на GPU-станции (форк Дмитрия)

Правило Дмитрия: всё тяжёлое — раскадровка, сведение, кадры Chromium, сборка mp4, листы кадров — только на станции tesla; на Mac — файлы и облачные вызовы (озвучка). Обёртка живёт в студии, `~/Projects/serial-studio/tools/remote_anim.py`: везёт движок и папку ролика на станцию (out/, qa/, frames/ и кеш голоса не едут), запускает там `build.py <имя> --skip-tts` в контейнере с Playwright 1.64 (Chrome Headless Shell 156 — тот же браузер, что рисует на Mac) и забирает результат на те же места.

```bash
WORK=$PWD/eps/<имя> .venv/bin/python tts.py                               # озвучка — облако, на Mac, из корня движка
python3 ~/Projects/serial-studio/tools/remote_anim.py <имя> --no-render   # раскадровка и звук → build/story.json, audio/mix.wav
python3 ~/Projects/serial-studio/tools/remote_anim.py <имя> --sheet       # лист кадров → eps/<имя>/qa/sheet.jpg
python3 ~/Projects/serial-studio/tools/remote_anim.py <имя>               # рендер → eps/<имя>/out/<имя>.mp4 и <имя>_small.mp4
RENDER_SCALE=4 ENCODE_CRF=12 python3 ~/Projects/serial-studio/tools/remote_anim.py <имя>   # мастер 2K
python3 ~/Projects/serial-studio/tools/remote_anim.py <имя> -- render.py --story eps/<имя>/build/story.json --at 1,2.5,4 --sheet eps/<имя>/qa/at.jpg
python3 ~/Projects/serial-studio/tools/remote_anim.py <имя> -- scene_test.py <сцена> '<json p>' --dur 6 --at 0,1,2,3 --out eps/<имя>/qa/scene_<сцена>.jpg
```

- Пути в своей команде — от корня движка; назад едут пути из `--sheet`/`--out` (и `--pull ПУТЬ`). Черновые сцены из `--extra` и `--story` едут сами (и из `qa/`, и из `/tmp`).
- Озвучка остаётся на Mac: облачный голос, но `tts.py` ещё склеивает фразы ffmpeg-ом и numpy (лёгкий шаг; перенос на станцию — отдельная задача). Личные входы `eps/<имя>/source/private` на станцию не едут.
- Станция не ответила — код 201 и строка; рендер на Mac сам не запускается (так задумано). Упал рендер — хвосты `qa/render_*.log` станции печатаются в терминал.
- Лист станции против листа Mac (сверка 03.11 на `example`): 99,1% пикселей совпадают в пределах 1/255; расходятся края букв (FreeType на Linux против CoreText на Mac — контур в 1 пиксель) и мягкие свечения. На глаз не различить. Обновился Playwright в `.venv` — обёртка предупредит: образ пересобрать с той же версией.
- Шрифты сцен — только из `fonts/` через `@font-face`: системных шрифтов Mac (`'Helvetica Neue'`, `Arial`, `serif`) на станции нет, там подставятся Liberation/DejaVu.

## Правила для сцен

- `SCENES.имя = function (u, p, d, t) { ... return svg; }` внутри `(() => { ... })();`. `u` — время от начала кадра, `p` — параметры из story.py, `d` — длина кадра, `t` — время ролика. **Все времена в `p` абсолютные** (время ролика), сравнивай их с `t`.
- Детерминированно: никаких `Math.random`, `Date`, состояния между вызовами. Случайность — `hash(n)`, `noise1(x)` из lib.js. Кадр N должен рисоваться одинаково при любом порядке рендера.
- Кадр 360×640. Всё важное — выше `GROUND = 372`; ниже — зона субтитров, держи её тёмной и пустой.
- Первый кадр каждой сцены сам по себе понятный и красивый (он может стать первым кадром ролика).
- В каждом кадре что-то живёт: свет дышит, тень ползёт, кольцо бежит, предмет дрожит. Статичная картинка = слайд-шоу.
- Красный `#ff3030` — только опасность и интерфейс наблюдения. Без крови и скримеров, без полноэкранных вспышек.
- Без брендов и логотипов. Люди плоские, как `person()` в lib.js или крупнее (см. `k_bedroom.js`), без «зловещей долины».
- В шапке файла опиши сцену, каждый параметр `p` и подходящие камеры — по образцу `engine/scenes/k_*.js`. Добавь строку в `docs/SCENES.md`.
- Правишь существующую сцену — без нового параметра она должна рисоваться ровно как раньше (старые ролики не должны поменяться).

## Раскадровка (story.py)

- `E.shot(сцена, t_start, p, cam)` — кадры идут подряд; `cam = {z0, z1, ox, oy}`: зум от z0 к z1 за время кадра, ox/oy — точка, к которой зумим (смещение от центра 180,320).
- **Картинка меняется не реже чем раз в 3 секунды**: новый кадр, другой план той же сцены или заметное событие. Кадр короче 0.8 с не нужен.
- Склейки ставь чуть раньше слова (`- 0.05`), чтобы картинка и слово совпадали.
- Плашки: `E.add("stk", t0, t1, n="1", text="Не отвечать", x=180, y=96, rot=-2)` — правило; `E.add("chip", ..., text=..., color="red"|"dark"|"white"|"green", x, y)` — короткая подпись; `track` (рамка «ВЫ»: `box=[x,y,w,h]` или `keys`), `vf` (видоискатель: REC, таймкод `clock0`, `bare=True` — только уголки), `peek` (передний план укрытия: `peek="door"|"slit"|"corner"`).
- `E.write(fades=..., kicks=[...], cap_off=..., marks={...}, look="night")`: `kicks` — толчки камеры на ударные моменты, `marks` — времена для mix.py, `look` — цвет (`night`, `mono`, `muted`, `cctv`, `riso` или без фильтра).

## Звук (mix.py)

- `M = Mix()`; `M.put(звук, время, db(-20))` кладёт эффект; `M.beds()` — гул комнаты, дрон, часы; `M.curve([(t, дБ), ...])` — огибающая; `M.duck()` — приглушить фон под голосом; `M.finish(amb, music)`.
- Синтез без файлов: `tone`, `chime`, `click`, `thump`, `creak`, `whoosh`, `heartbeat`, `speaker` (голос из динамика), `reverb`. Свои звуки — `ev("файл.mp3")` из `sfx/`, музыка — `M.music([...])` из `music/` (источники — README в этих папках).
- Под голосом всегда тихий фон; каждое событие на экране (скрип, щелчок, сигнал) слышно. Музыка на 9–13 дБ тише голоса, обрывается в момент поворота сюжета.

## Озвучка: грабли

- Реплики в кавычках — точка **за** кавычкой: `«Я не расслышала».` Иначе голос прочитает «точка».
- Ударения edge-tts иногда ставит неправильно. После озвучки: `python stress_check.py --root eps/<имя> --listen` (доп. пакеты: `pip install -r requirements-stress.txt`) — список рискованных слов и файл `build/stress_listen.m4a`, где эти фразы идут под номерами. Дай пользователю послушать; где диктор ошибся — замени слово или поставь знак ударения U+0301 после ударной гласной (за́мок). Автоматике не верь: решает ухо.
- Числа в тексте пиши словами («в три часа ночи»); в субтитрах они станут цифрами по таблице `NUMS` в storylib.py — дополняй её.

## Чек-лист перед полным рендером

- Первый кадр: сразу понятно, где мы и что страшно; первая фраза — хук.
- Субтитры не перекрывают важное, плашки не налезают друг на друга.
- Камера не уводит главный объект за край и под субтитры.
- Зло что-то делает каждые 5–7 с; картинка меняется ≤ 3 с.
- Финал вытекает из уже сказанных правил, без новых правил в последние 10 с.
- Слова совпадают с картинкой (говорим «колонка» — видим колонку).
- Громкость: build.py печатает LUFS; итог около -15.
