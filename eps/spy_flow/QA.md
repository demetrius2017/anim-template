- Снята блокировка черновика, добавлены отсутствующие сцены и `mix.py`.
- Зум детального плана уменьшен с предложенных 1,10–1,16 до 1,02–1,06 для сохранения полей; детальные планы получили собственные акценты.
- «Часть прибыли» и «Взносы / из зарплаты» устраняют впечатление, что вся прибыль/зарплата направляется в индекс. «Состав меняет комитет» поясняет обновление индекса.
- Доходность и максимальная просадка показаны отдельно; период и Horizon FULL подписаны. Веер акций и размеры компаний обозначены как условные. Круг рынка не приравнен к мировому рынку или SPY.
- Добавлены дисклеймер, тихий синтезированный фон, звуки событий и финальное затухание. Музыкальная пульсация прекращается на переходе к риску.
- Исправлена зависимость проверки ударений: `transformers>=4.40,<5`; версия 5.20.1 ломала контракт tokenizer/ONNX в ruaccent, с 4.57.6 проверка проходит. Код общего движка и пример не изменены.

## Воспроизведение проверок

Из корня репозитория, Python из `.venv`:

```sh
python build.py spy_flow --no-render
python build.py spy_flow --skip-tts --sheet
python stress_check.py --root eps/spy_flow --listen
python build.py example --skip-tts --sheet
python build.py spy_flow
```

Все пять команд прошли, финальная сборка завершилась с кодом 0 за 191 с. Финальная сборка записывает stdout/stderr в `qa/build_full.log`, PID — `qa/build_full.pid`, код завершения — `qa/build_full.exit`. Сверка хэшей сцены/озвучки до и после полной сборки — `qa/candidate_before_render.json`, `qa/candidate_after_render.json`.

Сгенерированные медиа, аудио, кадры, листы и логи игнорируются Git. В коммит входят исходники сцен, каталог, план, сценарий, раскадровка, звук, этот отчёт и исходные материалы выпуска.
