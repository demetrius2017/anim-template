# Сеть внутри сети — основа для параллельной работы

Шаг 1 готов. Это озвучка, единый стиль и договорённости для авторов сцен; девять производственных файлов `un_*.js` пока намеренно пустые заглушки. Полный ролик не отрендерен и не принят. Коммит и публикация не выполнялись.

## Речь и стоимость

13 фраз дословно из BRIEF.md; id в script.json — строки `"1"`…`"13"`, id сцены — `p.s = "s1"`…`"s13"`. Начало 0,05 с; паузы между фразами 0,22–0,50 с (после финальной 0,10 с); естественные паузы внутри фраз оставлены в TTS. В оригинале большинство межфразовых пауз 0,2–0,4 с, редкие — около 0,6 с.

Провайдер `elevenlabs_ws`, модель `elevenlabs/eleven-v4`, готовый голос **Brian**, stability=0,70, similarity=0,75, speed=**1,22**. Не клонирование и не имитация диктора оригинала. Пробы одной и той же первой фразы: `audio/audition_Brian.mp3`, `audio/audition_George.mp3`. Brian: медианная F0 125,98 Гц, IQR 30,18 Гц; George: 141,59 / 45,18 Гц. Brian выбран как более низкий и интонационно ровный; это акустические показатели и описание каталога, не заявленная слуховая приёмка. Метод и исходные измерения — `qa/voice_comparison.json`.

WaveSpeed eleven-v4 не поддерживает параметр speed: `tts_ws.py` применяет ffmpeg atempo без изменения высоты. Первая начитка при 1,0 дала 84,60 с с плашкой; 1,22 возвращает спокойный рассказ к утверждённым 66–72 с без изменения слов. Повторное распознавание ускоренных файлов — на **tesla**, через `remote_whisper.transcribe`, без локальной модели. Не совпавшие с распознаванием слова/числа получают интерполированные времена своего участка, как в tts_openai; это не фонемное выравнивание. Сырые транскрипты и исходные границы лежат в `audio/.ws_cache/*/speed_1.22.json`, монтажные — в `build/words.json`.

**Итог:** 67.32185 с — конец последнего звучащего слова; 67.79131 с — шкала озвучки с паузами и хвостом; 70.79131 с — весь ролик с финальной плашкой ровно 3,00 с. WAV рассказчика содержит также тишину плашки.

**Расход: $0,08512 по проверенному тарифу**, 15 выполненных генераций (14 Brian, включая один дополнительный дубль s5, + одна проба George); музыка $0, распознавание на собственной tesla. Это расчёт на уровне запросов, не разница общего баланса при параллельных работах. `ledger.jsonl` содержит reserve/submitted/completed, prediction id, цену и хэш результата. Резерв считается до POST и жёстко ограничен $1; неизвестная отправка не повторяется. Повторная сборка и смена speed используют исходный платный файл. API key берётся кодом из .env, в артефактах его нет.

Документация, сверенная 30.10.2026: [WaveSpeed API](https://wavespeed.ai/docs/docs-api/elevenlabs/elevenlabs-eleven-v4), [каталог голосов](https://wavespeed.ai/docs/docs-api/elevenlabs/elevenlabs-voice-id). `/model/price` для 54 символов первой фразы: $0,00432.

## Контракт для авторов

- Менять только свой `engine/scenes/un_<name>.js`; сохранять имена `SCENES.un_*`, `p.s`, `p.mode`, `p.K`. Все заглушки возвращают `UN.wrap('')`. Не подменять их общей тестовой сценой: она только для сравнения стиля.
- Холст **360×640**, рендер ×3 = **1080×1920**, **30 fps**, только #000/белый/серые. Смысловые объекты в x≈20…340, y=16…370. Субтитры y=410…480, 2–5 слов, PT Serif Italic, белые, без плашки. Внутренний clip `UN.wrap` заканчивается y=370.
- Общая камера нейтральна `{z0:1,z1:1,x0:0,x1:0,y0:0,y1:0,drift:0,kicks:0}`. Плавные перелёты делать через `UN.project` внутри сцен. Так смена фразы не сбрасывает внешний зум. Согласовать пограничные позы A→B→C→D→E. Для непрерывных деталей использовать абсолютный `t`, не `u`.
- `K.s1`…`K.s13` — начало фраз, `K.sN_end` — конец. Все значения абсолютные секунды. Полный словарь — `build/cues.json`; `K.words["N"]` содержит `{w,t0,t1,token_id}` каждого слова, включая повторения. `build/scene_handoff.json` — краткая машиночитаемая таблица.
- Смысловые K: `number/weight/inside`, `atom/ordinary`, `second/bond/strength/oxygen/hydrogen/bond_value/bond_weight`, `low_energy/enough/reaction/activation`, `join/molecule/layer`, `stack/molecules/cells/organisms/biosphere`, `random/learn/mistake/mutation/shift/loss/years`, `inner/neurons_number/neurons/you`, `third/chatgpt`, `nested_1/nested_2/nested_3`, `cosmos/beginning/number_return/weight_return/power`, `hypothesis/if_true/universe/next/token`, `silence/maybe/final_you/card/end`.
- `UN.at(K,key,t,duration)` даёт плавные 0…1 после слова. Относительная длительность анимации допустима; начало события привязывать к K. Не вводить собственные абсолютные секунды. Не должно быть неподвижных участков >3 с: на длинных s3/s4/s7/s11 нужны события от промежуточных слов и постоянное спокойное движение камеры.
- В s3 сначала 436 (H–H), затем на `K.bond_value` 463 кДж/моль (O–H); в s5 угол воды 104,5°; в s7 конец счётчика ≈3,8 млрд лет; s8 86 000 000 000; s11 10⁸⁰. Остальные факты только из source/brief.md. Научная метафора явно ограничена финальной гипотезой.
- В s13 с `K.silence` подложка и эффекты обнулены; остаётся голос. С `K.card` финальная плашка уже рисуется общими overlays story.py: **автор un_tokens должен убрать пилюлю/фоновые объекты**, оставив `UN.wrap('')`. Плашка до `K.end`, ровно 3 с. Не дублировать её внутри сцены.

## API un_lib.js (window.UN)

Все функции рисования возвращают SVG-строку, без состояния между кадрами. `UN.wrap(svg)` добавить один раз в конце сцены: фон, defs, область рисования. Нельзя оборачивать каждый объект отдельно (будут дубли SVG id). CSS действует только на `#root:has(#un-world)`, другие эпизоды не меняются. Сцены подключаются автоматически: `render.py` загружает все `engine/scenes/*.js` по алфавиту; ссылки на UN разрешаются при вызове сцены, поэтому файл atom может быть раньше lib.

| Вызов | Параметры / результат |
|---|---|
| `UN.project([x,y,z], camera)` | Мир: x вправо, y вниз, z вдаль. Камера `{cx:180,cy:216,f:620,distance:620,yaw:-.35,pitch:.22,scale:1}`; углы в радианах. Результат `{x,y,z,s}`. Радиус шара умножать на s; дальние объекты рисовать первыми. |
| `UN.sphere(x,y,r,opts)` | Экранные координаты; `{opacity:1,glow:1,highlight:true}`. Белая кайма, прозрачное тело, блик, мягкий ореол. |
| `UN.thread(a,b,opts)` | Концы `[x,y]` или `{x,y}`; `{opacity:.4,width:.55}`. |
| `UN.weight(x,y,rx,ry,opts)` | По умолчанию rx34,ry5; `{opacity:.65,angle:0}`; angle в градусах. |
| `UN.block([x,y,z],opts,camera)` | Размеры `{w:172,h:96,depth:105}`, сетка `{nx:13,ny:8,nz:3}`, `{opacity:1,rays:true,dots:true}`. nx/ny минимум2, nz минимум1. |
| `UN.surface(heightFn,opts,camera)` | `heightFn(x,z)` возвращает y; `{span:270,steps:27,opacity:.24}`. |
| `UN.token(x,y,text,opts)` | Центр пилюли; `{w:auto,h:23,size:10,opacity:1,cursor:false}`. Курсор мигает по t в вызывающей сцене. |
| `UN.mono(x,y,text,opts)` | IBM Plex Mono; `{size:9,anchor:'start',opacity:.9,glow:false}`. |
| `UN.italic(x,y,text,opts)` | PT Serif Italic; те же опции, размер20 по умолчанию. |
| `UN.bokeh(t,opts)` | Детерминированные дальние световые диски; `{count:32,opacity:1,seed:10}`. |
| `UN.polyline(points,opts)` | Массив экранных точек; `{width:.55,opacity:.4,close:false,glow:false}`. |
| `UN.smooth(x)`, `UN.hash(n)` | Ограниченное сглаживание 0…1; детерминированное число 0…1. |

Шрифт `fonts/PTSerif-Italic.ttf`, лицензия `fonts/PTSerif-OFL.txt` (SIL OFL 1.1). Источник: Google Fonts / ParaType, `ofl/ptserif/PT_Serif-Web-Italic.ttf`. Уже имеющийся IBM Plex Mono сохранён.
