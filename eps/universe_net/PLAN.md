## API un_lib.js (window.UN)

Все функции рисования возвращают SVG-строку, без состояния между кадрами. `UN.wrap(svg)` добавить один раз в конце сцены: фон, defs, область рисования. Нельзя оборачивать каждый объект отдельно (будут дубли SVG id). CSS действует только на `#root:has(#un-world)`, другие эпизоды не меняются. Сцены подключаются автоматически: `render.py` загружает все `engine/scenes/*.js` по алфавиту; ссылки на UN разрешаются при вызове сцены, поэтому файл atom может быть раньше lib.

| Вызов | Параметры / результат |
|---|---|
| `UN.project([x,y,z], camera)` | Мир: x вправо, y вниз, z вдаль. Камера `{cx:180,cy:216,f:620,distance:620,yaw:-.35,pitch:.22,scale:1}`; углы в радианах. Результат `{x,y,z,s}`. Радиус шара умножать на s; дальние объекты рисовать первыми. |
| `UN.sphere(x,y,r,opts)` | Экранные координаты; `{opacity:1,glow:1,highlight:true}`. Белая кайма, прозрачное тело, блик, мягкий ореол. |
| `UN.thread(a,b,opts)` | Концы `[x,y]` или `{x,y}`; `{opacity:.4,width:.55}`. |
| `UN.weight(x,y,rx,ry,opts)` | По умолчанию rx34,ry5; `{opacity:.65,angle:0}`; angle в градусах. |
| `UN.block([x,y,z],opts,camera)` | Размеры `{w:172,h:96,depth:105}`, сетка `{nx:13,ny:8,nz:3}`, `{opacity:1,rays:true,dots:true}`. nx/ny минимум2, nz минимум1. |
| `UN.surface(heightFn,opts,camera)` | `heightFn(x,z)` возвращает y; `{span:270,steps:27,opacity:.24}`. |
| `UN.token(x,y,text,opts)` | Центр пилюли; `{w:auto,h:23,size:10,opacity:1,cursor:false}`. Курсор мигает по t в вызывающей сцене. |
| `UN.mono(x,y,text,opts)` | IBM Plex Mono; `{size:9,anchor:'start',opacity:.9,glow:false}`. |
| `UN.italic(x,y,text,opts)` | PT Serif Italic; те же опции, размер20 по умолчанию. |
| `UN.bokeh(t,opts)` | Детерминированные дальние световые диски; `{count:32,opacity:1,seed:10}`. |
| `UN.polyline(points,opts)` | Массив экранных точек; `{width:.55,opacity:.4,close:false,glow:false}`. |
| `UN.smooth(x)`, `UN.hash(n)` | Ограниченное сглаживание 0…1; детерминированное число 0…1. |
