Общие правила для всех авторов сцен v2 «Сеть внутри сети».

Прочитай: CLAUDE.md, docs/SCENES.md, eps/universe_net/BRIEF_v2.md, eps/universe_net/build/script.json, eps/universe_net/build/cues.json, eps/universe_net/story.py, engine/scenes/un_lib.js. Текст ролика менять нельзя. Времена только из p.K: абсолютные, из cues.json, никаких секунд руками.

Контракт сцены:
- SCENES.<имя>=function(u,p,d,t){return UN.wrap(body(t,p.K||{},p.mode));}; плюс SCENES.<имя>.body=(t,K,mode)=>сырой SVG без wrap и без чёрного фона.
- Переход на границе сцен: входящая сцена владеет наплывом. Она вызывает SCENES.<предыдущая>.body(t,K,mode) при абсолютном t, если функция есть, иначе проявляется из чёрного. Наплыв 0,4–0,9 с. Никаких скачков яркости, двойных wrap, дублирующихся id в SVG.
- Границы сцен и что идёт за чем: build/scene_handoff.json. Сцену пишет другой автор — не читай его незаконченный код и не правь чужие файлы; если нужной функции ещё нет, работает запасной вариант из чёрного. Сводить будет отдельный шаг.
- Детерминизм: только t и K, без Math.random, Date, состояния между кадрами, u и d не влияют на движение.
- Всё важное y=16..370, субтитры y=410..480, ни один объект и подпись не выходит за кадр 360×640. Нет неподвижных участков длиннее 3 с. Движение спокойное, никаких рывков.
- Пиши только свои файлы из задания. Другие Codex работают параллельно.
- Проверяй через scene_test.py и .venv/bin/python render.py --story eps/universe_net/build/story.json --at <секунды через запятую> --sheet <файл>, смотри листы кадров как изображения, включая границы сцен и моменты ключевых слов. Лист клади в eps/universe_net/qa/.
- Не публиковать, не пушить, не коммитить. Ключи не печатать. Платных вызовов нет. Озвучку не запускать: она готова. Пример `python build.py example --skip-tts --sheet` не должен сломаться, если ты трогаешь общий файл; общие файлы трогать нельзя без крайней нужды.
- В конце запиши статус-файл из задания: первая строка PASS или FAIL, дальше 5–10 строк: что сделано, какие листы смотрел, что не проверено. Сцены соседей могут ещё не существовать: проверяй их отсутствие через typeof и опциональные вызовы.
