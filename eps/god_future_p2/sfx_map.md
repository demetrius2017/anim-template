# SFX — god_future_p2 (без музыки)

Голос: есть (audio/voice_narr.wav), слова — выравнивание озвучки.

Событий: 34 (в паузах 33, под речью 1); перекрывают слова: 1 (3%, цель < 10%). Музыки и подложки нет.

Звуки — записи моделей, не синтез кодом: копии набора «Что такое время» (Stable Audio 3 и ElevenLabs SFX — его kit.json) и новые Stable Audio 3 Small-SFX на tesla ($0). Код только раскладывает файлы: счётчик дней и бомба — из двух записанных щелчков, низкие/высокие варианты — сдвиг высоты записи, у малого удара и у факела (огонь порядка) — гармоники 150–1500 Гц для динамика телефона. Происхождение каждого файла — `audio/sfx/kit.json`, мастерская — `serial-studio/lab/out/god_future_sfx/`.

Плюс спектрограммы и огибающие всех дублей (глазами). Человеческим ухом звуки не слушались.
