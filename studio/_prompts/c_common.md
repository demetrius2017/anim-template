Проект «Movie Studio» — продолжение форка anim-template (README.md, CLAUDE.md, docs/ в корне). Прочитай исследования studio/research/r1_prior_art.md, r2_genai_api.md, r3_story_library.md, r4_craft_style.md, r5_engine_audit.md (особенно разделы «Что берём в Movie Studio»). Владелец хочет: ролики уровня профессиональной команды; научный разбор темы до сценария; библиотеку сценарных шаблонов по жанрам (научный, драма, экшн и др.); вычитку сценария агентами (комната сценаристов/консилиум/хакатон); вклад по порядку режиссёра, монтажёра, звукорежиссёра (паузы, фокусы, переходы); наборы стилей с подходящей динамикой и готовыми дизайн-решениями; где нужно — генерация вставок качественными моделями по API (например, WaveSpeed). Оркестраторы — Claude Code (навык /animate) и Codex ($animate); тяжёлую работу по директиве владельца делает Codex. Ядро SVG/JS-движка сохраняем.
Пиши по-русски, конкретно, 1200–2500 слов. Это консилиум: дай СВОЮ позицию с аргументами, отметь, с чем из исследований не согласен.
